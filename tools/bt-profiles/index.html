CLEAVE HHJP設定

CLEAVE HHJP（ZMK）用の設定画面です。ZMK Studio と同じ仕組みで、ブラウザ（Chrome・Edge）から接続して設定します。
JISキーボードレイアウトで表示します。

  • キー割当: レイヤーごとのキーの割り当てを変えます。組み合わせキーや長押しも、仮想キーボード・一覧・ZMK の書き方（&lt 1 LBKT など）や短い書き方（LCTL+C、LT(1,A)）で設定できます。
  • マクロ: 文章やキー操作をテキストで書き、ZMK のマクロ定義（macros）に変換します。ZMK はマクロをあとから書き換えられないため、出力を .keymap に入れてビルドします。
  • BT: Bluetoothプロファイルの登録状況の確認と、ペアリング解除・切断をします。
  • レイヤ監視: 今効いているレイヤーの割り当てを表示します。小窓にして、他のアプリの上に浮かせられます。

キー割当の変更は右上の「書込」でまとめてキーボードに書き込みます。「エクスポート」「インポート」で、全体を .keymap 形式で保存・読み込みできます。
キーボードが手元にない場合は「デモで試す」で、模擬キーボードを相手に一通りの操作を試せます。

BT とレイヤ監視には、確認用ファームウェア cleave_hhjp_left-btinfo のログ用ポートへの接続が必要です（接続後に「ログポートに接続」）。キー割当は通常の左手用ファームウェアでも使えます（ZMK Studio 対応ビルド）。

組み合わせ
待機ms

    プレビューは実際に送られる順番です。黄色がキー操作、緑が待機、枠付きは押したままの操作です。

    ZMK のマクロ定義キーマップ編集ツールを開く

    ZMK はマクロをキーボード上で書き換えられません。この定義を .keymap の / { … } の中に入れてビルドし、キー割当で &ID を割り当てます。ZMK Studio 対応ビルドでは、定義したマクロはキー割当の「一覧から選ぶ」に出ます。

    書き方
    書き方動作
    そのままの文字その文字を入力します（半角英数字と記号のみ）。タブは Tab になります。
    エディタ内の改行見た目を整えるだけで、送られません。Enter を送るには {ENTER} と書きます。
    {ENTER} {F5}キーを1回押します（ZMK のキー名。KC_ 付きも可）。
    {LCTL+C} {LCTL+LSFT+K}修飾キーとの組み合わせを押します。
    {TAB*3}同じ操作を繰り返します。
    {+LSFT} … {-LSFT}キーを押したままにし、あとで離します。
    {WAIT:200}200ミリ秒待ちます。
    {{ }}波かっこ自体を文字として入力します。

    修飾キー名: LCTL LSFT LALT LGUI / RCTL RSFT RALT RGUI（CTRL SHIFT ALT GUI CMD WIN も可）。記号の変換は右上で選んだPCの配列に合わせます。日本語などの全角文字はマクロでは送れません。マクロは、このブラウザに保存されます。

    プロファイル外の登録（bond）

    —

    左右分割の接続（右手側）のbondは通常ここに出ます。それ以外があれば、プロファイルから外れた古い登録の可能性があります。

    ペアリング解除・全解除はキーボード側の登録だけを消します（左右分割の接続は消えません）。解除後はPC/スマホ側のBluetooth設定からもキーボードを削除してください。各操作はボタンを2回押すと実行されます。表示するのはアドレスと状態だけで、ペアリングの鍵は出力しません。
