# CLEAVE HHJP設定（キー割当・マクロ・BT・レイヤ監視）

[← トップページに戻る](../../README.md)

CLEAVE HHJP（ZMK）用の設定画面です。ZMK Studio と同じ仕組み（Studio RPC）で、ブラウザ（Chrome・Edge）から接続して設定します。画面構成は ogm10-Jupiter の設定ツールに合わせています。

**https://oogamizin.github.io/KeyBord.CLEAVE-HHJP-VerOGM/tools/bt-profiles/**

## 使い方

1. パソコンの Chrome か Edge で上の URL を開きます（Safari と Firefox は Web Serial に対応していないため使えません）。
2. 「キーボードに接続」を押し、一覧から ZMK Studio 用のシリアルポートを選びます。
3. 上部のボタンで「キー割当」「マクロ」「BT」「レイヤ監視」を切り替えます。右上には、接続中のキーボード名とログポートの状態が出ます。
4. BT とレイヤ監視を使うときは「ログポートに接続」を押し、もう一方のシリアルポートを選びます（確認用ファームウェア `cleave_hhjp_left-btinfo` が必要です）。
5. キー割当の変更は、右上の「書込」でまとめてキーボードに書き込みます。まだ書き込んでいない変更があると、件数付きのオレンジ色になります。
6. 終わるときは右上の「接続解除」を押します。書き込んでいない変更があるときは確認が出ます。

キーボードが手元にないときは「デモで試す」で画面の動きを確認できます。

## できること

### キー割当

- 盤面でキーを選び、文字で入力するか、仮想キーボード・キー入力モード・選択式で割り当てます。
- 文字は ZMK の書き方（`&kp LC(C)`、`&lt 1 LBKT`、`&mo 1`、`&bt BT_SEL 0`）のほか、短い書き方（`LCTL+C`、`LT(1,LBKT)`、`MO(1)`、`LSFT_T(A)`）でも書けます。
- 「長押でレイヤー」「長押で修飾」で、今のキーに Layer-Tap・Mod-Tap を付けられます。「長押解除」でタップ側のキーだけに戻します。
- 「一覧から選ぶ」に、Bluetooth・出力先・システム・メディア・日本語のキーと、このキーボードのカスタム behavior（bt1〜bt5、btclr、マクロなど）が並びます。
- 選んでいるキーの「初期設定」で、そのキーだけをリポジトリの `config/cleave_hhjp.keymap` の割り当てに戻せます（書込で反映）。
- 「初期設定に戻す」で、キーボードのキー割当をファームウェアの初期設定に戻せます（ZMK Studio の Restore Stock Settings と同じ。すぐ反映）。
- 「レイヤーをテキストで編集・レイヤー単位でのインポート」で、レイヤー全体をまとめて編集できます。.keymap の `bindings = < … >;` の中身をそのまま貼れます。
- 変更は「書込」を押すまで反映されません。書き込み後に読み戻して照合します。「変更破棄」で書き込んでいない変更を捨てます。
- 書き込みにロック解除が必要なときは、`&studio_unlock` のキーを押すよう案内します。

### マクロ

- 文章やキー操作をテキストで書き、ZMK のマクロ定義（`macros`）に変換します。キー操作は `{LCTL+C}`、`{TAB*3}`（繰り返し）、`{+LSFT}…{-LSFT}`（押したまま）、`{WAIT:200}`（待機）と書きます。
- 記号は、選んだパソコン側の配列（JIS / US）に合わせてキーコードにします。
- ZMK はマクロをキーボード上で書き換えられないため、出力した定義を .keymap に入れてビルドします。ZMK Studio 対応ビルドでは、定義したマクロはキー割当の「一覧から選ぶ」に出ます。
- マクロはこのブラウザに保存されます。

### BT

- Bluetooth プロファイルごとの登録先アドレスと状態（選択中・接続中・登録済・空き）を表示します。
- プロファイルごとのペアリング解除・切断と、全プロファイルの解除ができます（ボタンを2回押すと実行）。

### レイヤ監視

- 今有効なレイヤーのキー割り当てを、基板の配置どおりに表示します。レイヤーを切り替えると表示も追従します（ログポート接続時）。
- レイヤーの用途を、左に色分けした枠と名前で表示します。
- キーの左上の青い文字は、Shift を押しながら打つと出る文字です（JIS 配列）。
- 専用キーの説明を、盤面の下に凡例として出します。
- 「小窓で表示」で、他のアプリの上に浮かせておけます。

### 全体のエクスポート・インポート

- エクスポート: 全レイヤーのキー割当を .keymap 形式で保存します。リポジトリの .keymap を元に、keymap ノードだけを今の内容に置き換えます（書き込んでいない変更も含む）。
- インポート: .keymap を読み込み、書き込んでいない変更として入れます。確かめてから「書込」で反映します。

### 独自トリガ

「キー割当」と「レイヤ監視」の左のレイヤー一覧の下にある「独自トリガ」を押すと、BT 操作・出力先・カスタム behavior・レイヤー操作などの特殊なキーの一覧が出ます。項目にカーソルを乗せると、使うキーの位置が盤面に色付きで出ます。

### 仮想キーボード（デモ中のみ）

- 「デモで試す」の間、右上の「仮想キーボード起動」で、クリックで動かせる CLEAVE HHJP を出せます。
- デモ用の模擬キーボードに書き込んだ割り当てで動きます。レイヤーの切り替えはレイヤ監視に、BT 操作は BT の表示に反映されます。
- 右クリックで押したままにでき（もう一度右クリックで離す）、Shift や Fn などとの組み合わせはこれで試します。

### ファーム更新

- 接続中は、左上に「ファーム更新」ボタンが出ます。確認用ファームウェアのログポートに接続していると、キーボードのファームウェアの版（ビルド元のコミット）と、公開中の最新版（`firmware/latest.json`）を比べ、新しい版があればオレンジの「ファーム更新 ●」になります。
- 書き込むファームウェア（左手・左手のBT確認用・右手・設定リセット・SoftDeviceなし版）を選び、「更新を始める」で書き込みモードにします。左手はログポート接続中ならボタンだけで書き込みモードになります。右手や、ログポートを使わないときは、XIAO のリセットボタンを素早く2回押すか、3:System レイヤーの T（左手）・Y（右手）の `&bootloader` キーを押します。
- 現れた「XIAO-SENSE」などのドライブを「ドライブを選んで書き込む」で選ぶと、最新版をダウンロードして（ハッシュを照合して）書き込みます。ドライブを選べないときは「ファイルを保存」して、手でドライブにコピーします。
- 「手元の UF2 を使う」で、Actions などから取り出したファイルも書き込めます。
- 最新版は、main のファームウェアを GitHub Actions がビルドしたときに `firmware/` へ自動で公開されます。接続前の画面からも直接ダウンロードできます。

## ogm10-Jupiter の設定ツールとの違い

ZMK の仕組み上、次の機能はありません。

- マクロのキーボード上での書き換え（定義の出力のみ）
- タップダンス・コンボ・キーオーバーライド・QMK 設定（ZMK では .keymap とビルドで設定します）
- 右手の自動書き込みモード切替（右手は &bootloader キーかリセットボタンで切り替えます）
- 通常版ファームウェアの版の確認（版は確認用ファームウェアのログポートでのみ分かります）
- エンコーダー（CLEAVE HHJP にはありません）

## 制約

- ここで保存した設定は .keymap より優先されます。.keymap の内容に戻すには「初期設定に戻す」を使います。
- ZMK Studio と同時に開くと、通信が混ざることがあります。片方ずつ使ってください。
- レイヤ監視の追従と BT は、確認用ファームウェア `cleave_hhjp_left-btinfo` のログポートが必要です。
