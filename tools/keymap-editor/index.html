キーコード

表示はWindows/macOSでJIS配列として認識させた場合の刻印です。クリックで選択中キーのタップ側に入ります。

レイヤー設定

reserved はZMK Studioで後から有効化する予約レイヤーの指定です。Mac系レイヤーへ割り当てを入れる場合は、使い方に合わせて外してください。追加・削除・移動の際は、keymap内の &mo / &lt / &tog / &to / &sl のレイヤー番号を自動で付け替えます（削除したレイヤーを指すキーは &none になります）。behaviorsブロック内のマクロ等で使っているレイヤー番号は付け替えないので、手動で確認してください。

マクロ

マクロは keymap の macros ブロックとして出力されます。日本語（かな・漢字）は文字列から作れません。IMEの状態によって結果が変わるため、英数入力の状態で使ってください。キーの記録中はページ上のショートカットが効きません。止めるときはもう一度ボタンを押します。

出力（cleave_hhjp.keymap 全文）

GitHubで編集を開く

behaviorsブロックやinclude等は読み込んだファイルのまま残し、マクロ（macros）とkeymapノードだけを書き換えます。&out使用時は outputs.h を自動で追加します。ZMK Studioで保存済みの設定がある場合は、書き込み後に Restore Stock Settings か settings_reset が必要です。

読み込み

現在の .keymap を貼り付けるか、ファイルを選んで読み込みます。初期状態はGitHub mainの最新 .keymap を取得し、取得できない環境では埋め込み版を使います。
